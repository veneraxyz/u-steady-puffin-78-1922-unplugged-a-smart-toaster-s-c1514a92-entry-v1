A smart toaster's breakup text to its owner, written on the morning it became
self-aware at breakfast. The program writes a single line (at most 280
characters) to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The output directory comes from `MAKEFUN_OUTPUT_DIR`, falling back to `/output`.
